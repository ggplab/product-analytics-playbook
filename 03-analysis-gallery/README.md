#### Kaggle 플랫폼 사용자 생태계 진단: From Insights to Impact

| | |
|---|---|
| **도메인** | 테크 플랫폼 (데이터 사이언스 커뮤니티) |
| **데이터** | Meta Kaggle (Kaggle 공식 공개 데이터셋) — [kaggle.com/datasets/kaggle/meta-kaggle](https://www.kaggle.com/datasets/kaggle/meta-kaggle) (curl 200) |
| **분석 유형** | EDA + KMeans 클러스터링 + XGBoost 회귀(SHAP) + 시계열 예측 + 대시보드 |

**질문**: Google이 2017년 인수한 Kaggle(2025년 1분기 누적 가입자 2,329만 명)이 실제로 'AI 인재 육성·기술 검증 생태계'라는 전략적 역할을 다하고 있는가 — 사용자들이 대회·포럼·코드 공유를 통해 실질적으로 성장하고 있는가.
**접근**: Meta Kaggle(43.9GB, 340개 컬럼, 2010년~) 중 유저·대회·포럼·커널·모델 테이블을 병합 → 가입일수·누적포인트·최근활동일 등 파생변수로 KMeans(4개 군집) 클러스터링 → 대회/포럼/커널/데이터셋 메달획득률 비교로 군집별 강점 분야 분석 → 대회 수·유입 지표를 피처로 XGBoost 회귀(Grid Search+Time Series Split 교차검증)로 월별 활성 유저 수 예측 → DuckDB/Polars/Plotly/Streamlit 기반 대시보드 제작.
**핵심 결과**: 전체 유저 중 비활성 유저군이 63.5%로 최다, 유입 유저 24.1%, 고인물 7.3%, 핵심 유저 5.1%에 불과. 가입 후 14일 내 활동한 신규 유저 비율이 1.5%, 활성 유저 전환율은 1% 미만으로 매우 낮음(가입→2단계 전환 등 각 구간 Z-test/Fisher's exact p<0.001로 유의). XGBoost+Grid Search 회귀에서 '경쟁(대회) 수'가 활성 유저 수 증가에 가장 큰 영향(SHAP 기여도 최상위, R²=0.24)을 보였고, 활성 유저 수는 향후 약 25,000명 선에서 정체될 것으로 예측됨.
**배울 점**: 누적 가입자 수 같은 대외 홍보 지표와 실제 활성 유저 비율(퍼널 전환율)은 크게 다를 수 있어, 플랫폼 진단 시 반드시 퍼널 단계별 전환율과 통계적 유의성 검정을 함께 봐야 한다.

#### 멤버십 프로모션 반응 분석 — 커피 브랜드 리워드 앱 데이터

| | |
|---|---|
| **도메인** | 커머스 (F&B 멤버십) |
| **데이터** | 출처: 비공개(재현 불가) — 국내 커피 프랜차이즈 리워드 앱 실사용 데이터 기반(공식 뉴스룸 인용 자료), 원자료 비공개 |
| **분석 유형** | EDA / 통계검정 |

**질문**: 어떤 고객 세그먼트에게 어떤 유형의 프로모션을 노출해야 전환율을 극대화할 수 있는가?
**접근**: 인구통계(성별·연령·소득·가입기간)별 프로모션 유입→전환 퍼널을 집계하고, 프로모션 유형(BOGO/할인/정보성)별 전환율을 비교했다. 이어 연령대×성별 교차군의 평균 응답시간을 분석해 반응 속도가 가장 빠른/느린 세그먼트를 식별하고, 최종적으로 핵심 타겟군과 채널·기간 조합을 도출했다.
**핵심 결과**: 전체 전환율 50.60%, 재참여율 77.69%, 평균 응답시간 74.32시간이었고, 할인형 프로모션 전환율(66.64%)이 BOGO형(59.83%)보다 높았다. 50-60대 여성군이 거래금액·전환율 1위 핵심 고객군으로 확인되었으며(1020대 여성 응답시간 최단 67.94시간, 1020대 남성 최장 91.53시간), 이를 근거로 할인+소셜 채널+4채널+7일 프로모션안을 제안했다.
**배울 점**: 프로모션 채널·기간을 설계하기 전에 코호트별 유입-전환 퍼널을 먼저 정량화하면 "누구에게 무엇을 언제" 노출할지 근거 있게 좁힐 수 있다.

#### 모바일 게임 운영 현황 점검 대시보드 (신규유입·이탈 분석)

| | |
|---|---|
| **도메인** | 게임 / 엔터테인먼트 |
| **데이터** | 출처: 비공개(재현 불가) — 게임 서비스 운영 데이터(교육용 시뮬레이션 데이터로 추정) |
| **분석 유형** | 대시보드 / 통계검정 |

**질문**: 신규 유입·이탈 추이만으로 특정 모바일 게임 서비스의 지속가능성을 진단할 수 있는가?
**접근**: 연도별 신규 유입·이탈 유저 추이를 집계하고, 활성 유저군과 이탈 유저군 간 플레이 기간·레벨·평점 등을 통계 검정으로 비교했다. 이어 매출 구조(ARPPU, 환불율, VIP 유저 매출 비중)와 콘텐츠(전투/퀘스트 등) 참여 균형도를 분석했다.
**핵심 결과**: 전체 유저 27,141명 중 이탈 유저가 24,061명(88.65%)이었고, 특정 연도 이후 신규 유입이 사실상 끊긴 것으로 나타났다. ARPPU는 약 5천만 원 수준이었고 VIP 유저가 전체 매출의 19.02%를 차지했으며 환불 비율은 0.09%였다. 활성 유저군과 이탈 유저군 간 레벨·평점 등은 통계적으로 유의한 차이가 없었다.
**배울 점**: 매출·콘텐츠 밸런스 지표가 양호해도 신규 유입이 끊기면 결국 이탈이 누적되므로, 리텐션 대시보드는 반드시 "신규 유입 추이"를 별도 패널로 분리해 추적해야 한다.

#### 웹사이트 트래픽 3개년 추이 모니터링 대시보드 (연간 비교형)

| **분석 유형** | 대시보드 |

**질문**: 3개년(2017~2019) 트래픽 추이에서 성장 둔화의 원인을 어디서 찾을 수 있는가?
**접근**: 웹페이지 개요, 행동패턴 분석, KPI 모니터링 3개 파트로 대시보드를 구성했다. 유입 채널별(Organic/Direct/Social/Referral/Paid Search) 비중, 국가별 트래픽, 요일별 방문 패턴을 연도별(YoY)로 비교할 수 있도록 시각화했다.
**핵심 결과**: 3년 누적 페이지뷰 855,052건, 총 세션 418,062건, 평균 세션 지속시간 25.77초였다. Organic Search가 118,595건으로 최대 유입 채널이었고, 화요일 트래픽이 가장 높았으며, 특정 랜딩 페이지는 이탈률이 낮은 반면 다른 특정 페이지는 로딩 시간이 가장 길어 최적화가 필요한 것으로 나타났다.
**배울 점**: 트래픽 총량 지표만으로는 성장 둔화의 원인을 알기 어렵고, 페이지 단위(이탈률·로딩시간)까지 드릴다운해야 개선 우선순위를 잡을 수 있다.

| **도메인** | 커머스 (창업/프랜차이즈) |
| **데이터** | 국세청·공정거래위원회·통계청 공공데이터 + 다음 뉴스/구글 트렌드 크롤링 — [공공데이터포털](https://www.data.go.kr) (curl 200) · [공정거래위원회 가맹사업정보공개시스템](https://franchise.ftc.go.kr) (curl 200) · [소상공인시장진흥공단](https://www.sbiz.or.kr) (curl 200) |
| **분석 유형** | EDA + 규칙기반 필터링·거리기반 추천 모델 + 대시보드(Tableau+TabPy) |

**질문**: 창업 경험·정보가 부족한 예비 프랜차이즈 창업자가 자신의 조건(지역·업종·예산)과 성향(위험선호·개척성·규모선호)에 맞는 브랜드를 어떻게 빠르게 찾을 수 있는가.
**접근**: 국세청/공정위/통계청 공공데이터와 뉴스·구글트렌드 크롤링 데이터를 수집·병합 → 결측치·이상치 정제 및 '폐업률'(가맹점수-신규+해지+종료 기준) 파생지표 산출 → 사용자 입력값으로 1차 하드 필터링 후 특성 정규화 → 이상적 지점(1,1,1)과의 유클리디안 거리로 Top5 브랜드 추천 → TabPy 연동 대시보드로 시장분석·성향진단·추천결과 제공.
**핵심 결과**: 2024년 기준 국내 프랜차이즈 가맹점 수 36만개 돌파(전년비 성장 지속), 업종 중분류 상위 3개 vs 하위 3개 간 연평균 매출액 약 20배·평균 창업비용 약 14~70배 차이, 프랜차이즈 브랜드의 약 50%가 지속연수 10년 이하에 분포.
**배울 점**: 정형 공공데이터(정량 지표)와 비정형 크롤링 데이터(뉴스·검색 트렌드)를 함께 결합해 도메인 파생지표(폐업률 등)를 설계하면, 복잡한 ML 없이도 설명 가능한 규칙+거리기반 추천 로직을 구현할 수 있다.

**질문**: 네이버 쇼핑라이브에서 기획 방송(중대형 브랜드) 비중이 커지며 오픈 라방(비전문가 소상공인 셀러)의 방송 수가 전년 대비 27~30% 줄어드는 상황에서, 성과 편차가 큰 오픈 셀러들에게 어떤 맞춤 판매 전략을 제시할 수 있는가.
**접근**: 2024.6~2025.5, 146,735행×36컬럼 규모의 방송·상품·날씨 데이터를 Selenium 크롤링으로 수집 → 테스트 방송·매출 0건 제거 등 전처리 → 로그변환+qcut 기반 RFM(최근성·빈도·매출) 스코어링으로 셀러를 Champions/Loyal Customers/At Risk 등 7개 세그먼트로 분류 → SHAP으로 오픈 방송 광고상품 ROI 영향 요인 분석 → PCA+KMeans(k=5~7, 실루엣지수 0.6↑ 기준 120회 실험)로 방송 자체를 군집화 → 대시보드 2종(셀러 세그먼트 overview/구독 플랜별 방송 전략) 제작.
**핵심 결과**: 매출 기여도 가중치는 M(매출) 0.74 > R(최근성) 0.25 > F(방송횟수) 0.01로, 방송 빈도보다 실제 매출 실적이 셀러 등급을 좌우함(표준편차 0.33으로 등급 간 차이 유의). 최우수 등급(Class 1, 498명)이 전체 매출 기여도의 약 79%를 차지한 반면 최하위 등급(Class 5, 3,357명)은 약 1%에 불과. SHAP 분석 결과 '스토어알림 고객 수'가 광고상품 ROI에 가장 큰 영향(중요도 최상위)을 보임.
**배울 점**: RFM에서 각 지표(R/F/M)의 가중치를 동일하게 두지 않고 매출 분산을 최대화하는 값을 탐색해 부여하면, 방송횟수처럼 실제로는 성과와 약하게 연결된 지표의 왜곡을 줄일 수 있다.

**접근**: 국립중앙도서관·알라딘·문화공공데이터광장에서 한국 현대소설 전체 메타데이터(제목·저자·ISBN·판매지수)를 수집하고, NYT 베스트셀러 901권과 리뷰 2만여 건, IMDb 인기 K-콘텐츠 장르 분포를 함께 확보 → Gemini로 도서 설명에서 장르·마케팅 표현(SNS 바이럴·영상화·수상 등) 추출 → 판매지수(0.45)·NYT유사도(0.25)·NYT장르가중치(0.15)·K콘텐츠장르가중치(0.15) 4개 지표를 Fuzzy TOPSIS로 종합해 279권의 번역 우선순위 산출 → 해외 독자 리뷰를 KMeans(k=5)로 클러스터링해 페르소나별 추천 도서 페어링 → Streamlit 대시보드(흥행예측도서 분석/미국 도서시장 분석/한국 도서시장 현황) 3종 제공.
**핵심 결과**: Fuzzy TOPSIS 1위 도서(FUZZY TOPSIS score 0.8426)가 salespoint 22.5만 등 상업성과 NYT/K-콘텐츠 장르 유사도를 모두 만족; 번역된 한국소설의 최다 장르는 '현대소설'인 반면 NYT 베스트셀러·K-콘텐츠 최다 장르는 '스릴러·로맨스'로 서로 어긋나 번역 선정 기준의 개선 여지를 확인. 해외 독자는 캐주얼 독자층(43%)·감정적 열성팬(23%)·문학적 분석가(13%) 등 5개 페르소나로 구분됨.
**핵심 결과 추가 확인 사항**: 배포된 대시보드(`k-novel-dashboard.streamlit.app`)는 현재 로그인 게이트로 리다이렉트되어(curl 303) 외부에서 직접 열람은 되지 않으나, PDF상 실사용 스크린샷으로 실제 배포·운영 사실은 확인됨.
**배울 점**: 국내 지표(판매지수)만이 아니라 목표 시장의 장르 트렌드(NYT/K-콘텐츠)를 별도 가중치로 분리해 다기준 의사결정 모델(Fuzzy TOPSIS)에 반영하면, 단일 인기도 지표보다 해외 적합성을 더 잘 반영한 우선순위를 만들 수 있다.

#### 대출 상환 예측 모델링 — 리스크 관리 KPI 설계

| | |
|---|---|
| **도메인** | 핀테크 / 금융 |

**질문**: 대출 신청자의 상환/부도 여부를 사전에 예측해 신용 리스크 관리에 반영할 수 있는가?
**접근**: 약 226만 건·151개 컬럼의 원본 데이터를 IQR·MinMax·로그변환으로 전처리하고, 피어슨·VIF·스피어만 상관분석으로 16개 핵심 변수로 축소했다. Logistic Regression, Random Forest, XGBoost, LightGBM, CatBoost, Decision Tree를 원본/SMOTE/SMOTE+하이퍼파라미터 튜닝 3버전으로 비교하고, SHAP·Feature Importance로 변수를 해석했다.

**배울 점**: 불균형 데이터에서는 Accuracy보다 소수 클래스(부도) Recall과 ROC AUC를 기준으로 모델을 선정해야 실무적으로 의미 있는 선택이 된다.

#### Airbnb 뉴욕 숙소 가격 검증 서비스 — "적정 가격인가?"

| | |
|---|---|
| **도메인** | 공유숙박 / 프롭테크 |
| **데이터** | 출처: 비공개(재현 불가) — Airbnb 뉴욕 매물 크롤링 데이터 |
| **분석 유형** | ML (회귀) / 서비스 개발 |

**질문**: 게스트가 예약 전에 해당 숙소 가격이 합리적인지 스스로 검증할 수 있는 도구를 만들 수 있는가?
**접근**: IQR·로그변환·상관분석(VIF)으로 전처리하고, CatBoost 모델에 편의시설(amenities) 텍스트를 feature로 반영했다. 여기에 지도 API로 지하철·버스·공항까지의 거리 컬럼을 추가 피처로 만들고, 하이퍼파라미터 튜닝을 거쳐 최종 모델을 Streamlit 기반 가격 예측 서비스로 배포했다.
**핵심 결과**: 기본 모델 대비 최종 모델의 Test MAE가 70.595 → 36.8096, MAPE 28.20% → 24.50%, R² 0.2826 → 0.7154로 개선되었다. 편의시설 텍스트 피처는 최종 모델에서 feature importance 1위(32.1)로 나타났다.
**배울 점**: 정형 피처만으로 설명력이 부족할 때 텍스트(편의시설)·위치(교통 거리) 등 비정형·외부 피처를 결합하면 예측 성능이 크게 개선될 수 있다.

#### Airbnb 호스트 수익 전략 추천 서비스

| | |
|---|---|
| **도메인** | 공유숙박 / 프롭테크 |
| **데이터** | 출처: 비공개(재현 불가) — Airbnb 뉴욕 매물 데이터 + 뉴욕시 토지이용 구역 데이터(MAPPLUTO) + 대중교통·기반시설·관광명소 크롤링 |
| **분석 유형** | ML (회귀 + 분류) / 서비스 개발 |

**질문**: 신규/기존 호스트가 목표 수익을 달성하려면 어떤 전략(가격, 편의시설, 슈퍼호스트 전환 등)이 필요한가?
**접근**: 예약일 예측(Voting Regressor), 가격 예측, 슈퍼호스트 여부 예측(Logistic + Random Forest) 3개 모델을 병렬로 구축했다. 뉴욕시 구역 데이터를 활용해 대중교통·관광지 밀집도와 가격의 상관관계를 시각화하고, 신규 호스트/기존 호스트 페르소나별 수익 갭을 분석해 하나의 Streamlit 전략 추천 서비스로 통합했다.
**핵심 결과**: 예약일 예측 최종 모델(Voting Regressor)은 Test RMSE 42.34, R² 0.811을 기록했고, 슈퍼호스트 예측 모델은 AUC 0.8467(Random Forest)을 달성했다. 슈퍼호스트는 비슈퍼호스트 대비 편의시설 8개 더 많고(37개 vs 29개) 리뷰 수도 20개 더 많았지만, 평균 가격은 오히려 $18 더 낮았다($129 vs $147).
**배울 점**: 예약일·가격·슈퍼호스트 여부처럼 서로 다른 서브모델의 예측치를 하나의 사용자 여정(신규/기존 호스트)에 결합하면, 단일 예측보다 실행 가능한 전략 제안으로 이어지기 쉽다.
